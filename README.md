# Netflix Movies & TV Shows Analytics Dashboard

## 📌 Project Overview
This project features an interactive, brand-themed **Power BI Dashboard** that analyzes Netflix's extensive catalog of movies and TV shows. Designed with Netflix’s iconic dark mode and red aesthetic, the dashboard uncovers key insights regarding content distribution, top creators, cast frequencies, geographical availability, and historical release trends.

The goal of this project is to transform raw data into a highly interactive, business-ready visual application that helps stakeholders understand content trends and production hotspots.

---

## 📊 Key Features & Visualizations

### 1. Executive Summary KPIs
* **Total Content:** High-level metrics tracking total shows (`5,337`), total movies (`5,189`), total titles (`5,335`), and global reach across `605` country classifications.
* **Dynamic Filtering:** An intuitive country slicer allows users to instantly filter the entire dashboard by region.

### 2. Content & Creator Deep Dives
* **Top 5 Shows by Cast:** Identifies the most prominent actors/performers appearing in Netflix shows (e.g., Samuel West, Jeff Dunham).
* **Top Listed In (Genres):** A horizontal bar chart showcasing the most dominant genres and content categories.
* **Director Insights:** Separate breakdowns tracking the top 5 directors for both movies and TV shows.

### 3. Geographical Distribution
* **Interactive Global Map:** A customized, dark-themed geographic map visually highlighting content density and focus regions across the globe.

### 4. Advanced Tooltip Integration (Page 2)
* **Historical Trends Tooltip:** An interactive, custom tooltip page featuring an area graph (`Count of show_id by release_year`) that allows users to hover over visuals and see the exponential growth of Netflix content since 1900, peaking sharply post-2010.

---

## 🛠️ Tech Stack & Design Layout
* **Business Intelligence Tool:** Microsoft Power BI Desktop
* **Theme & Styling:** Customized Netflix Branding (Hexagonal dark textured background with premium high-contrast red accents `#E50914`).
* **Data Features:** Custom Tooltip Pages, Cross-Filtering, Custom Map Styles, and Grid Layout alignment.

---

## 💡 Key Insights Discovered
* **Balanced Library:** Netflix maintains a relatively balanced split between standalone movies (~5,189) and multi-episode TV shows (~5,337).
* **The Streaming Boom:** Content releases remained relatively flat for decades but experienced an explosive, exponential spike starting around 2015, capturing the peak of the digital streaming era.
* **Genre Dominance:** Documentaries, Stand-Up Comedy, and International Dramas rank among the highest-produced content types on the platform.

## 🚀 How to Run the Project
1. Clone this repository to your local machine.
2. Ensure you have **Microsoft Power BI Desktop** installed.
3. Open the `.pbix` file included in this repository.
4. Interact with the slicers, charts, and hover over data points to see the custom tooltip in action!
